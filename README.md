# Hikayat Kelip

A story-driven 3D action-adventure for the browser — silat combat, stilt-roof parkour and wau gliding on the
fantasy island of Pulau Seri — playable instantly on PC and on phones in landscape.

## Stack

Three.js r186 (`WebGPURenderer` with automatic WebGL2 fallback, TSL shaders), Rapier physics
(`@dimforge/rapier3d-compat`), vanilla JavaScript ES modules, Vite for dev/build, Vitest and Playwright for tests,
Vercel for hosting and functions, Supabase for the competitive backend (Phase 6). Assets are generated by Blender
5.2 scripts.

## Setup

Requirements (Windows, as installed by the setup in `docs/PROGRESS.md`): Node.js 24 LTS, Git, Google Chrome,
Blender 5.2 LTS, FFmpeg and KTX-Software on `PATH`.

```powershell
git clone https://github.com/Izaffsd/Hikayat-Kelip.git
cd Hikayat-Kelip
npm ci
npm run dev        # http://localhost:5173
```

Never run `npx playwright install`: visual tests use the installed Chrome (`channel: 'chrome'`).

## Commands

| Command | What it does |
| --- | --- |
| `npm run dev` | Vite dev server with hot reload |
| `npm run build` | Production build into `dist/` |
| `npm run preview` | Serves the production build on port 4173 |
| `npm run lint` | ESLint (flat config) |
| `npm run format` / `npm run format:check` | Prettier write / check (Markdown is never reformatted) |
| `npm test` | Unit tests (Vitest) |
| `npm run test:visual` | Headed Chrome on the real GPU, WebGPU and forced-WebGL2 projects; build first with `npm run build` |
| `npm run assets` | Regenerates every model, texture and audio file headless (toolchain check until Phase 2) |

## URL options (testing)

| Option | Effect |
| --- | --- |
| `?webgl=1` | Forces the WebGL2 backend (the debug overlay has the same toggle) |
| `?debug=1` | Opens the debug overlay on start (also F3, or a three-finger tap on touch) |
| `?test=1` | Exposes a read-only `window.__hk` hook used by the Playwright tests |

## Controls

| Action | Keyboard + mouse | Gamepad | Touch (landscape) |
| --- | --- | --- | --- |
| Move | WASD / arrows | Left stick | Floating joystick, left half |
| Camera | Mouse (click to lock) | Right stick | Drag on the right half |
| Jump / glide (hold in air) | Space | A | Large button, bottom right |
| Sprint | Shift (also builds automatically at full tilt) | Left stick click | Push the joystick far |
| Strike / heavy | Left mouse / F | X / Y | Strike button |
| Langkah (step) | Q | B | Langkah button |
| Tangkis (parry) | Right mouse | LB | Tangkis button |
| Context (kuncian, interact) | E | RB | Context button |
| Call Kelip | R | RT | Firefly button, top left |
| Lock-on | Middle mouse / Tab | LT | Automatic (assist) |
| Pause | Esc / P | Start | Pause button, top right |

Keyboard and gamepad bindings are remappable (stored with the player's settings).

## Deployment (Vercel)

The repository is connected to Vercel with the **Vite** framework preset; `vercel.json` sets the build, cache headers
(hashed assets are immutable for a year) and content types for `.wasm`, `.glb`, `.ktx2` and `.ogg`. Every push to
`main` deploys production; every other branch gets a preview URL. Functions live in `/api` (Node.js runtime).

## Environment variables

See [`.env.example`](.env.example). Production values are set only in the Vercel dashboard, never committed.

| Variable | Where | Purpose |
| --- | --- | --- |
| `TELEMETRY_ENABLED` | Server | `false` turns off `/api/event` |
| `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` | Browser (read-only, RLS) | Leaderboards (Phase 6) |
| `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` | Server only | Writes from Vercel Functions (Phase 6) |
| `RUN_TOKEN_SECRET` | Server only | Signs run tokens and daily seeds (Phase 6) |
